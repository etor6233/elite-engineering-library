## Executable behavior

The schema is `elite-project-readiness-gate/v2`. It fails closed when:

1. a required capability has no connected journey;
2. a journey references an unknown or non-required capability;
3. the P1 vertical slice references a nonexistent journey;
4. any persona, role, interface, authorization, API, domain, data/effect, audit, response/error, help, training, support, update, test or recovery evidence list is empty or unsafe;
5. release, help, training and support semantic versions differ;
6. an unknown field, duplicate key, secret, absolute path or traversal path appears;
7. any prior A–H advisory, capability, dependency, document, mapping, source, license, operation or pack-plan condition remains incomplete.

A PASS authorizes materializing the selected first slice. It never authorizes production.
