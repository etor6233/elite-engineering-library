## Runtime wiring and limits

- API includes durable background loops: CPU always and minimum one active instance. Request-only CPU or minimum zero is rejected by executable validation. Manual suspension is a distinct drained operation. Cloud Run's documented 10-second termination interval differs from the existing API's 15-second shutdown budget: forced termination/recovery on this target is NOT_RUN, a technical target test, not a missing secret.
- Web and API retain separate workload IAM and end-user OIDC. The shared backend transport attaches `X-Serverless-Authorization` from Google's identity metadata while preserving user `Authorization`. Protected, public and catalog clients use the same helper. Default/disabled mode preserves local behavior. Only the configured HTTPS `run.app` origin/audience is accepted in cloud mode; custom domains require a separately reviewed contract. Metadata responses are bounded, never logged, and never treated as proof of product-role authorization.
- ARCA remains homologation only. The new .NET launcher imports a mounted PFX into CurrentUser/My and invokes the original worker Main in the same process; it changes no SOAP, fiscal or signing rule. Two readonly Secret Manager mounts supply `/var/run/secrets/arca/certificate/cert.pfx` and `/var/run/secrets/arca/password/password`. Mounted 0444 input bytes are copied bounded into the container user's private 0700 HOME as 0600 files, imported, then staging is removed. All UDS participants need the same effective UID and socket access. A synthetic Linux certificate fixture proves import/private-key signing/rejects, not ARCA connectivity or fiscal acceptance.
- API/web/worker/job/SQL/storage/identity/scheduler resource dependencies are in the stack manifest. Provider setup, target migration/restore, private-URL access, billing export, queue recovery and OCI runtime are NOT_RUN unless their actual target receipts exist.
- Existing adapted pnpm policy admits a specific Windows runtime and narrowly contained offline install. Linux archive/tool pins alone do not upgrade that admission. Exact projection bytes are required and original owners are reused; native Linux admission, dependency-store acquisition receipt and target SCA are explicit prerequisites, never mislabeled “missing credential”. No altered pnpm payload is redistributed in this pack.

Budgets and alerts are not an absolute shared spending ceiling. GCS CAS protects multi-worker intent; local SQLite is a single-controller observation journal, not a distributed database or tenant budget owner.
