# Implementation Packs

Este directorio contiene bloques completos que un agente puede materializar como archivos. No confundir con `architecture_packs/`: aquellos explican una arquitectura; estos deben producir código, configuración, migraciones y pruebas trazables.

## Regla de uso

1. Leer `markdown_system/PACK_CONTRACT.md`.
2. Seleccionar sólo packs compatibles con el `PROJECT_BLUEPRINT.md`.
3. Comprobar estado, licencia, versión, precondiciones y conflictos.
4. Materializar exactamente el manifest.
5. Ejecutar todos los gates indicados.
6. No elevar un pack a `REBUILD_VERIFIED` sin reconstrucción limpia y evidencia.

## Jerarquía

La base del sistema es portable y no pertenece a TypeScript, Go, Java ni Rust. Los adapters de lenguaje se seleccionan después del blueprint.
