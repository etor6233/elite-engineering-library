## Regla de uso inmediato

`REBUILD_VERIFIED / CONDITIONED` puede incorporarse sin una pausa ceremonial cuando el agente prueba y registra sus condiciones en el target. No equivale a `production-ready` universal. Ninguna configuración puede inventar reglas legales, credenciales, un proveedor, una nube, datos reales o capacidad medida.

El pack `TS-ENTERPRISE-WEB` se conserva como prototipo full-stack TypeScript histórico y `CANDIDATE`; no pertenece al perfil recomendado. El perfil web vigente usa el BFF autónomo y mantiene el dominio y la persistencia en Go/PostgreSQL.

## Orden de ampliación por proyecto

1. blueprint, journeys, datos y riesgos;
2. composición mínima compatible y vertical ejecutable;
3. identidad/proveedores/plataforma seleccionados;
4. seguridad, carga, observabilidad y recovery representativos;
5. evidencia, licencia del artefacto y promoción por versión.
