# Elite Engineering Library (Grok)

Biblioteca en la raíz de este repositorio (lectura). Escribe artefactos de proyecto en la raíz del proyecto consumidor.

## Divulgación progresiva — sólo este orden

1. **Esta skill** (aquí).
2. **`AGENTS.md`** — índice; no leas todo el corpus.
3. **Un mapa** — elige exactamente uno:
   - IA / ML / agentes → `AI_ENGINEERING_MASTER_MAP.md`
   - sistemas / plataforma → `SYSTEMS_ENGINEERING_MASTER_MAP.md`
4. **Un pack** — `markdown_system/PACK_PER_CLAIM_INDEX.md` para tu claim acotado.

## No cargar por defecto

- `AGENT_SYSTEM_START.md` (abre secciones puntuales sólo si un gate lo exige)
- `PROJECT_PACK_PLAN.md` o `markdown_system/FRANCHISE_COMPLETE_PACK_PLAN.md`
- `reconstruction_evidence/`
- todos los `implementation_packs/`

## Buscar primero; escalar si falta

Busca capability, pack, contrato o gate en la biblioteca. Si falta o está bloqueado, escala con evidencia — no inventes fuentes, packs, tests ni admisión.

## Pack-per-claim

Materializa **un** pack admitido por claim. Consulta **una** fila en `markdown_system/CAPABILITY_CATALOG.md`. `DISCOVERED|LICENSE_VERIFIED|CANDIDATE|CONDITIONED` no autorizan producción. Sin pack compatible: `implementation_packs/CAPABILITY_GAP_RESOLUTION_GATE.md`.

## Procedencia

Orquestación local `AUTHORED` para divulgación progresiva en Grok Build. No es código de producto upstream.
